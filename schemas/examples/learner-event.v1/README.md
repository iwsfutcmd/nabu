# Events before the lexical model (schema 1)

What `upgrade` and the restore of an old download read (`schemas/learner-event.v1.schema.json`).

- `valid/session-started.json`: A session as it was started.
- `valid/answer.json`: An answer credited per KC.
- `invalid/schema-2.json`: An event of schema 2 is not one of schema 1.
- `invalid/kc-credit-status.json`: A KC's credit is right, wrong or given.
